# Formulário Padrão

Este projeto é um formulário simples em HTML para coleta de dados pessoais e profissionais. Ele foi desenvolvido para ser fácil de usar e personalizar, utilizando tecnologias básicas da web: HTML, CSS e JavaScript.

## Funcionalidades

- Coleta de dados pessoais: nome, endereço, cidade e estado.
- Coleta de dados profissionais: natureza do cargo, áreas de interesse e mini-currículo.
- Validação simples com alerta ao enviar o formulário.
- Botão para limpar os dados preenchidos.

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (para exibir mensagem de confirmação ao enviar o formulário)

## Como Usar

1. Abra o arquivo `index.html` em um navegador web moderno.
2. Preencha os campos do formulário com seus dados pessoais e profissionais.
3. Clique em "Enviar" para enviar o formulário (aparecerá uma mensagem de confirmação).
4. Clique em "Limpar" para apagar os dados preenchidos e reiniciar o formulário.

## Estrutura do Projeto

- `index.html`: arquivo principal contendo o formulário.
- `index.css`: arquivo de estilos para o formulário.
